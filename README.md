# OCP Digital Twin — Manufacturing Intelligence

Application de pilotage industriel pour l'optimisation du procédé DAP/MAP.

## Structure
- `app.py` : point d'entrée
- `config.py` : constantes
- `auth.py` : authentification
- `data_utils.py` : manipulation des données
- `models.py` : modèles ML
- `viz_utils.py` : visualisations
- `sections.py` : onglets fonctionnels

## Installation
```bash
pip install -r requirements.txt
streamlit run app.py
